# Lavoro di gruppo - Esercizio serializzazione fakezone

Si vuole realizzare un'applicazione java che ci consenta di gestire gli ordini effettuati dagli utenti di "www.fakezone.sola" (link fake), un negozio online.
I prodotti che possono essere acquistati dati utenti registrati (di cui si vuole salvare userID, password, nome, cognome, data di nascta, sesso, codice fiscale, email, indirizzo, telefono)
sono caratterizzati da un coice alfanumerico, una descrizione, un insieme di immagini (si può salvare il percorso del file su disco) e un costo.
Degli ordini ci interessa sapere: data, elendo dei prodotti con le relative quantità, importo, stato (effettuato, spedito, consegnato).

## L'applicazione tramite interfaccia testuale deve consentire di:
- Inserire i dati utente;
- Visualizzare i dati di un utente;
- Inserire un prodotto;
- Visualizzare le informazioni di un prodotto;
- Inserire le informazioni di un ordine;
- Visualizzare le informazioni di un ordine;
- Modificare lo stato i un ordine;
- Esportare i dati;
- Importare i dati.

## Potenziamento
Si vuole consentire agli utenti di recensire i prodotti acquistati indicando un punteggio da 1 a 5 e una descrizione, registrando la data.

**Integrazione dell'interfaccia testuale**:
- Inserimento di una recensione;
- Visualizzazione delle recensioni di un prodotto.
